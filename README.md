Prompt Quizzer – A Quiz Game

Web Development – Lab Assignment 4

Objective

To create a simple quiz game using JavaScript.

Features

- Stores 5 questions in an array.
- Uses a function named "runQuiz()".
- Uses a for loop to display questions.
- Uses if-else conditions to check answers.
- Uses prompt() to take user input.
- Uses alert() to display results.
- Uses toLowerCase() and trim() to normalize answers.
- Displays the final score.

Technologies Used

- JavaScript
- Visual Studio Code
- Google Chrome

How to Run

1. Open the quiz.js file.
2. Copy the JavaScript code.
3. Open Google Chrome.
4. Open Developer Tools and select Console.
5. Paste the code and press Enter.
6. Answer all five questions.
7. View your final score.

Expected Output

The quiz displays five questions one by one and shows the final score after completion.

Conclusion

This project demonstrates the use of JavaScript arrays, functions, loops, conditional statements and user input methods.
